# NexoWatt EOS Admin 7.9.93 – Testkandidat

Dieser Stand basiert auf der freigegebenen Admin-7-Linie und ist für den abschließenden Realtest vorgesehen.

## Änderungen

- kompakte Anmeldung ohne internen Scrollbalken
- sichtbarer Herausgeber „NexoWatt“ in der Modulinstallation
- EOS Assist mit authentifizierter, rollenabhängiger Live-Systemabfrage
- EOS Assist bleibt schreibgeschützt und respektiert die Rechte von Admin, Installateur und Endkunde
- technischer Paketname `iobroker.eos-admin` bleibt für Installation und Kompatibilität unverändert

## Freigabe

Erst nach bestandenem Anlagen-, Rollen-, Reboot- und Backup-Test darf 7.9.93 auf npm `latest` gesetzt werden.
