# NexoWatt EOS Admin – Adapter Assets

Dieses Verzeichnis enthält die Adapter-Metadaten und sichtbaren Assets für den NexoWatt EOS Admin.

Wichtige Dateien:

- `admin.png` – NexoWatt EOS Adapter-Icon
- `admin.svg` – NexoWatt EOS SVG-Icon
- `favicon.ico` – Favicon für die Administrationsoberfläche
- `jsonConfig.json5` – Adapter-Konfigurationsschema
- `LICENSE-NEXOWATT.md` – proprietärer NexoWatt-Lizenzhinweis

Der technische Adaptername bleibt aus Kompatibilitätsgründen `admin`. Das npm-Paket wird als `@nexowatt/iobroker.admin` veröffentlicht und über das NexoWatt-Repository per `packetName` ausgeliefert.

Die Nutzung ist nur für von NexoWatt autorisierte oder lizenzierte Systeme erlaubt. Details stehen in `../LICENSE`, `../NEXOWATT_PROPRIETARY_LICENSE.md` und `../THIRD_PARTY_NOTICES.md`.
